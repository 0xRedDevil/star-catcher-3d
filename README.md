# Star Catcher 3D 🧚✨

A 3D endless flyer: guide the fairy along a glowing path through the night sky, catching stars and hearts while dodging stormy clouds. The 3D follow-up to [Fairy Star Catcher](https://github.com/0xRedDevil/fairy-star-catcher).

- ⭐ Star: +1 (watch for curvy star trails)
- 💖 Heart: +3 and an extra life (up to 5)
- ⛈️ Storm cloud: lose a life

The path speeds up the longer you fly. Top 5 scores are saved in the browser (localStorage).

## Controls

- **Keyboard:** ← → arrow keys (or A / D)
- **Mouse:** move left and right
- **Touch:** drag your finger left and right

## Play

No build step. It's a single `index.html` that loads [Three.js](https://threejs.org/) from a CDN, so it needs an internet connection. Serve the folder with any static server, or turn on GitHub Pages for the `main` branch.
